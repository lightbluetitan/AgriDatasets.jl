# Licensing Information for `AgriDatasets.jl`

This package, `AgriDatasets.jl`, includes datasets sourced from various R
packages and, in one case, an original dataset published on Zenodo. The
original content and values of these datasets have not been altered in
any way; only file format (CSV), variable naming (`snake_case`), and
in some cases the dataset name have been standardized for consistent use
in Julia.

## License

Each dataset included in `AgriDatasets.jl` is provided under its own
original license, exactly as documented above. This package does not
relicense any dataset; it aggregates independently-licensed data files
for the user's convenience (a "mere aggregation," in the sense used by
the GNU GPL), and each dataset's terms must be respected individually
when reusing that specific dataset.

The source code of `AgriDatasets.jl` itself (the functions in `src/`,
not the datasets) is licensed under the GPL-3.0-or-later license. See
[`LICENSE`](LICENSE) for the full text.

Machine-readable licensing metadata for all datasets is also available
in [`meta/datasets_metadata.csv`](meta/datasets_metadata.csv), consumable
programmatically via the `dataset_info()` function.
